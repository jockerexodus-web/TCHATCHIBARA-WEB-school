COMMENT UTILISER :
1. Placez tous les fichiers (index.html, style.css, script.js, data.js) dans le même dossier.
2. Ouvrez le fichier "index.html" dans votre navigateur web (Chrome, Firefox, etc.).

STRUCTURE :
- index.html : La page visible.
- style.css  : Les couleurs (Bleu #1e3a6e, Orange #f59e0b) et la mise en page mobile.
- script.js  : Permet de cliquer sur "2nde", "1ère", "Terminale" pour voir les matières.
- data.js    : C'est ici qu'il faut ajouter ou modifier les matières et les cours.

PROGRAMME GABON :
Le site inclut les filtres pour :
- Seconde (S, A, B)
- Première (Série A, B, C, D)
- Terminale (Toutes séries)
- Épreuves du Baccalauréat

POUR AJOUTER DES COURS :
Ouvrez "data.js" et ajoutez une ligne comme ceci :
{ matiere: "Nom de la matière", desc: "Description courte" },

DESIGN :
Le design respecte la charte graphique de l'image fournie :
- Fond bleu foncé.
- Titre en orange.
- Bouton "Voir les cours" arrondi.
- Header avec l'icône de chapeau de graduation.
